Why this map matters

Campus life is a linked system, not a set of isolated spots.

The map below treats Rutgers New Brunswick as a digital safety layer: a network of gates, shared devices, transit edges, and late-night spaces that continually exchange trust signals. A badge scan affects a residence hall. A public charger affects the student center. A Wi-Fi node affects the library, the bus stop, and the walk home. The point of the page is not just to mark locations, but to show how one layer of campus life ripples into the others.

Each marker opens a popup with a short summary and a link to a deeper profile lower on the page. The profiles expand the same idea with location views, descriptive data, and symbolic ratings so the relationships are readable at a glance and still detailed enough for analysis.

Layer Summary

  • Access control: gates, lobbies, and card readers
  • Connectivity: Wi-Fi, transit nodes, and shared network edges
  • Utility: charging, media, and other shared infrastructure
  • Commerce and routine: payment kiosks, vending, and food spaces
